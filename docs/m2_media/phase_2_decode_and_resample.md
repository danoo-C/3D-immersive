# M2 · Phase 2 — Decode and resample

**Status:** in progress · **Plan:**
[plans/phase_2_decode_and_resample.md](plans/phase_2_decode_and_resample.md)

## Goal

`core/io/media.py` opens any file F-5 lists and hands back its audio as
float32 at 48 kHz, one or two channels, together with the facts a `MediaFile`
records about it. A file it cannot open is a report with a reason, never an
exception — the same split M9 drew for theme files: code raises, input
reports.

After this phase a sample on disk can become samples in memory. Nothing plays
them and nothing draws them yet.

## Scope

**In:** decoding through `soundfile`; resampling to 48 kHz through `soxr`,
and only when the source rate differs; conversion of every bit depth to
float32; the `MediaFile` fields decoding determines — `name`, `source_rate`,
`channels`, `frames` at the project rate; the report for a file that is
missing, unreadable, not audio, truncated or empty; what a file with more than
two channels becomes.

**Out:** the content hash → phase 3. Peaks → phase 4. Running on a worker
thread → phase 6, which calls this; the module itself stays synchronous and
headless. Streaming from disk rather than holding audio in RAM — the roadmap
says hold it in RAM, and `03` leaves a decoded-audio cache for later if
re-decoding turns out to be too slow. Time-stretch and pitch-shift are out of
scope for v1 ([00](../00-overview.md)).

## Acceptance

- [ ] WAV, AIFF, FLAC, OGG and MP3 each decode, from fixtures generated by the
      tests rather than binaries committed to the repository — or, for any
      format the tests cannot write, one committed fixture and a note saying
      why.
- [ ] Whether a fallback decoder is needed for MP3 is settled, with the
      evidence in the Notes: which `libsndfile` each platform's `soundfile`
      wheel carries, and whether it reads MP3.
- [ ] Audio at 22.05, 44.1 and 96 kHz comes back at 48 kHz, with a frame count
      that follows a stated rounding rule exactly, and a test tone's frequency
      unchanged within a stated tolerance, measured rather than eyeballed.
- [ ] 16-bit, 24-bit and float sources all come back float32 within ±1.
- [ ] Mono stays one channel and stereo two. A file with more than two is
      handled the way the plan decides, and a test asserts it.
- [ ] A missing file, a directory, a text file renamed `.wav`, a truncated
      file and a zero-length file are each reported with a reason, and a
      battery asserts that no input raises.
- [ ] `core/io/media.py` imports no Qt and no `sounddevice` — which
      `test_layering.py` already enforces for everything under `core/`, and
      the phase confirms it is being checked rather than assuming.
